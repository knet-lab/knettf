特征对比：聚合前 vs 聚合后

聚合前（packet 级别）

来源：kafka_read_csv.py → dataset.csv，每行 = 一个包事件

字段说明
timestamp包事件发生时间
src_ip源 IP 地址
dst_ip目标 IP 地址
src_port源端口
dst_port目标端口
protocol协议类型（TCP / UDP / ICMP）
verdictCilium 对这个包的判决：放行还是丢弃
direction包的方向：进来（INGRESS）还是出去（EGRESS）
tcp_flags这个包携带的 TCP 标志位（SYN / ACK / FIN 等）
is_reply这个包是否是对方的回包
trace_reasonCilium 记录这个包的原因（策略命中、新连接等）
summaryHubble 描述文本（如 "TCP Flags: SYN"）
label0 = 正常 / 1 = 攻击

聚合后（flow 级别）

来源：aggregate_flows.py → flows.csv，每行 = 一条连接的统计汇总

类别特征说明
五元组src_ip源 IP 地址
dst_ip目标 IP 地址
src_port源端口
dst_port目标端口
protocol协议类型（TCP / UDP / ICMP）
时间flow_duration这条流从第一个包到最后一个包经过了多少秒
包数量 / 速率total_packets这条流一共抓到多少个包
fwd_packets其中正向（INGRESS）有多少个
bwd_packets其中反向（EGRESS）有多少个
fwd_ratio正向包占总包数的比例
packets_per_second每秒平均发了多少个包（速率）
IATiat_mean相邻两个包之间的平均间隔时间
iat_std包间隔的波动程度（越小说明越均匀，典型 flood 特征）
iat_min最短的包间隔
iat_max最长的包间隔
TCP Flags 计数syn_count这条流里 SYN 包的数量
ack_countACK 包的数量
fin_countFIN 包的数量（正常关闭连接）
rst_countRST 包的数量（强制断开）
psh_countPSH 包的数量（携带数据）
urg_countURG 包的数量（紧急数据，正常流量极少）
TCP Flags 比例syn_ratioSYN 占所有包的比例（SYN flood 时接近 1.0）
ack_ratioACK 占比
fin_ratioFIN 占比
rst_ratioRST 占比
回复reply_count收到对方回包的次数
reply_ratio回包比例（SYN flood 时几乎为 0，因为目标无法响应）
判决forwarded_count被 Cilium 放行的包数
drop_count被 Cilium 丢弃的包数
drop_ratio丢弃比例
方向is_bidirectional是否存在双向通信（只有单向说明对方没有响应）
协议is_tcp是否是 TCP 流量
is_udp是否是 UDP 流量
is_icmp是否是 ICMP 流量
端口is_well_known_port目标端口是否小于 1024（知名服务端口）
