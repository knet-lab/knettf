📋 概览

平台简介

NetSentinel 是一个面向 DevOps 和安全团队的一体化平台，提供 Kubernetes 集群实时监控、Terraform 配置安全扫描以及一键部署能力。

☸️ Kubernetes 监控
  • 连接并管理多个 K8s 集群
  • 查看 Namespaces、Pods、Deployments
  • 查看 Services、ConfigMaps
  • 实时查看 Pod 运行日志
🔍 Terraform 安全扫描
  • 上传或在线编辑 .tf 配置文件
  • 多工具联合安全扫描
  • HIGH / MEDIUM / LOW 风险分级
  • 扫描通过后一键 Terraform Apply
🏗️ 系统架构
层级技术栈说明
前端Vue 3 + Element Plus单页应用，访问地址 localhost:5173
后端Django REST FrameworkAPI 服务，地址 localhost:8000
认证JWT (SimpleJWT)Access Token 2小时，自动刷新
扫描引擎tfsec / checkov / trivy / tflint / terraform validate服务器本地执行
🔐 认证

登录与认证

打开登录页面
访问 http://localhost:5173/login，输入用户名和密码。
Token 自动管理
登录成功后系统自动获取 Access Token（有效期 2 小时）。Token 过期时平台会自动无感刷新，无需手动重新登录，直到 Refresh Token（7天）失效为止。
退出登录
点击右上角用户名旁的 Sign Out 按钮即可安全退出。
ℹ️
管理员账户可访问 /admin 路径进入后台管理界面，普通用户无法访问该路径。
☸️ Kubernetes

Kubernetes 集群监控

通过左侧侧边栏管理多个 Kubernetes 集群连接，点击集群后在右侧标签页查看各类资源。

添加集群

点击 Add 按钮
左侧侧边栏顶部点击蓝色 Add 按钮，弹出添加集群对话框。
填写集群信息
输入集群名称、API Server 地址、CA 证书、用户 Token 等连接信息。
选择集群查看资源
点击左侧集群列表中的任一集群，右侧自动加载该集群的资源信息。

资源标签页

标签页内容特殊功能
Namespaces 命名空间列表，显示名称、状态、创建时间 —
Pods Pod 列表，显示状态、IP、所在节点 点击 Logs 按钮查看实时日志
Deployments Deployment 列表，显示期望副本数 / Ready 数 —
Services 服务列表，显示类型、ClusterIP、端口 —
ConfigMaps 配置字典列表 —
⚠️
Pods、Deployments、Services、ConfigMaps 标签页需要先选择 Namespace 才能加载对应资源。切换 Namespace 后点击 Refresh 按钮刷新。

查看 Pod 日志

在 Pods 标签页，找到目标 Pod，点击右侧 Logs 按钮，弹窗中会实时显示该 Pod 的最新日志输出。

🔍 Terraform Scan

Terraform 安全扫描

管理你的 Terraform 配置文件，对其进行多工具安全扫描，确认无高风险问题后执行部署。

新建配置

点击左侧侧边栏顶部的 + New 按钮，弹出对话框，支持两种方式：

📁 上传文件

输入配置名称，选择本地 .tf 文件上传。

✏️ 在线编写

输入配置名称，在文本框中直接粘贴或编写 HCL 内容。

编辑配置内容

点击 Edit 按钮
Config Content 卡片右上角点击 Edit，文本框进入可编辑模式。
修改内容后点击 Save
修改完成后点击 Save 保存。保存后 is_scanned 状态会重置，需要重新扫描。
▶ 安全扫描

Security Scan

⚡ Full Scan

使用所有已启用的扫描工具对当前配置执行完整扫描。推荐日常使用。

🎯 Manual Scan

弹窗中勾选指定工具，只对选中的工具执行扫描。适合针对性排查。

当前内置扫描工具

工具检测方向输出格式
terraform_validate 语法与资源引用合法性验证 JSON
tflint 最佳实践、废弃用法、变量类型检查 JSON
tfsec 安全配置漏洞（权限过大、明文密钥等） SARIF
checkov 合规策略扫描（CIS Benchmark、K8s 安全策略） SARIF
trivy 配置错误与 CVE 漏洞扫描 SARIF
ℹ️
扫描过程在服务器端同步执行，期间页面显示 Scanning, please wait...，请勿关闭页面或重复点击。
🚀 Terraform Apply

Deploy — Terraform Apply

满足条件后，可直接在平台上执行 terraform apply，将配置部署到目标集群。

Apply 启用前提（缺一不可）

🚫
以下两个条件必须同时满足，Apply 按钮才会变为可点击状态：
① 已完成扫描（状态为 Scanned）
② 扫描报告中 HIGH 风险数量为 0

执行步骤

确认扫描通过
查看 Scan Report 中 Risk Summary，确认 HIGH 0。
点击绿色 Apply 按钮
Deploy 卡片中绿色 Apply 按钮变为可点击后，点击执行。
等待执行完成
平台依次执行 terraform init 和 terraform apply -auto-approve，完成后显示执行结果。
查看输出结果
Apply 完成后，卡片下方显示完整的终端输出，并标注 success 或 failed 状态及执行时间。
⚠️
.tf 文件中必须包含有效的集群连接信息（API endpoint、credentials），否则 terraform init 阶段会失败。

🛠 工具管理

TF Tools — 扫描工具管理

管理员可以新增、编辑、删除扫描工具，无需修改代码即可扩展扫描能力。

工具配置字段

字段说明示例
Name 工具唯一标识名称 tfsec
Command (cmd) 执行命令，支持 {target_dir} 和 {target_file} 两个占位符 tfsec {target_dir} --format sarif
Init Command 执行主命令前运行的初始化命令（可选） terraform init -backend=false
Output Format 工具输出格式 SARIF 或 JSON
Is Enabled 是否在 Full Scan 中启用 —

JSON 格式工具的字段映射

当 Output Format 选择 JSON 时，需要额外配置以下字段映射，告知平台如何从 JSON 输出中提取发现项：

配置项说明示例（tflint）
Items Path发现项列表在 JSON 中的点路径issues
Severity Field每条发现项中风险等级字段路径rule.severity
Severity Map工具原始等级 → 平台等级映射（JSON）{"error":"HIGH","warning":"MEDIUM"}
Rule ID Field规则 ID 字段路径rule.name
Description Field描述字段路径message
Location File Field文件路径字段range.filename
Location Line Field行号字段range.start.line
💡
添加新工具后，普通用户在 Manual Scan 中即可选择该工具，在 Full Scan 中也会自动包含（前提是 Is Enabled = true）。
⚠️ 附录

风险等级说明

等级含义对 Apply 的影响
HIGH 高危安全问题，存在明显安全漏洞或配置错误 阻断 Apply，必须修复后重新扫描
MEDIUM 中等风险，建议修复但不强制 不阻断 Apply，仍可部署
LOW 低风险提示，最佳实践建议 不阻断 Apply

扫描工具参考

📦 terraform validate

Terraform 官方验证命令，检查 HCL 语法正确性和资源引用合法性。输出 JSON，标识 error/warning 级别。

📦 tflint

Terraform Linter，检查废弃资源、变量类型错误、Provider 最佳实践等。输出 JSON。

📦 tfsec

专注于安全配置扫描，检测如权限过大、公开暴露端口、明文密钥等安全问题。输出 SARIF。

📦 checkov

覆盖 500+ 内置规则的合规扫描工具，支持 Terraform 中 Kubernetes Provider 资源的安全策略检测（CKV_K8S_* 规则族）。输出 SARIF。

📦 trivy

Aqua Security 出品的综合扫描工具，覆盖 IaC 配置错误与已知 CVE 漏洞。输出 SARIF。
